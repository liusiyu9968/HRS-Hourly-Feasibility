\section*{Code availability}
The optimization source code and reproduction instructions are intended
for release in a public repository. The empirical station transaction
records are commercially restricted, and processed representative-week
data may be requested from the corresponding author subject to
applicable access restrictions. The full numerical experiments require
a compatible Gurobi installation and an appropriate solver license.
